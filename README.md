# FreeCodeCamp Relational Database Projects

This repository contains the projects completed as part of the [FreeCodeCamp Relational Database certification](https://www.freecodecamp.org/learn/relational-database/). Each folder contains the SQL scripts and documentation needed to build and manage the database schemas required for the certification.

## Project Overview

| Project | Description |
| --- | --- |
| `celestial-bodies-database` | A database designed to store and query information about stars, planets, and other astronomical objects. |
| `cert-world-cup-database` | A relational schema tracking World Cup statistics, including teams, matches, and player goals. |
| `number-guessing-game` | A database-driven game implementation that uses stored procedures and triggers to handle game logic. |
| `periodic_table` | A structured database representing chemical elements, their properties, and their positions in the periodic table. |
| `salon-appointment-scheduler` | A business management system for scheduling appointments, managing services, and tracking customers. |
| `student-database` | A school management system for tracking student enrollments, courses, and academic records. |

## Tech Stack

- **Language:** SQL
- **Database System:** PostgreSQL (or the specific SQL dialect used during the course)
- **Concepts Applied:** Table normalization, primary and foreign keys, joins, views, stored procedures, and triggers

## How to Use

To run these projects locally:

1. Install a compatible SQL database, such as [PostgreSQL](https://www.postgresql.org/download/).
2. Create a new database for the specific project.
3. Execute the `.sql` files in the respective folder to set up the tables and seed the data.
4. Run the provided query scripts to verify the results.

## Goals

The goal of this collection is to demonstrate proficiency in:

- Designing relational schemas
- Ensuring data integrity through constraints
- Writing complex queries to extract meaningful information from a database
